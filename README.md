# Funa Battle Royal

Arena brawler online en 3D de humor absurdo, para hasta 10 jugadores (humanos y bots). Hecho con Godot 4.6.

Todos los personajes son parodias con nombres en clave y caras garabato. Cualquier parecido es pura coincidencia.

## Cómo jugar

1. Descargá [Godot 4.6](https://godotengine.org/download).
2. Abrí este proyecto con Godot y apretá F5.
3. En el lobby elegí personaje, cantidad de bots y "Crear partida".

Para jugar online, uno crea la partida y los demás se unen con su IP (puerto 7777 UDP).

En Windows también podés usar `jugar_solo_con_bots.bat` y `probar_2_jugadores.bat` (antes ajustá la ruta de Godot dentro de cada archivo).
